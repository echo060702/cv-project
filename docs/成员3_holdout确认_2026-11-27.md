## 核验与边界

- 推理前核对完整 dev 冻结链、21 个已有 checkpoint 哈希；确认 holdout 与 train/dev 的 ID/group 不重叠、1,200 个图像文件哈希与原审计一致。
- holdout 执行协议先于模型推理保存；所有逐图预测均可重算指标。保留原冻结文件，确认事实记录在独立目录，不改写其历史 holdout_evaluated=false。
- 本机 CPU / PyTorch 2.5.1 / Python 3.12.4；此前 dev 是 GPU / PyTorch 2.7.1。推理前对 16 张 dev 图像做环境检查，最大概率差约 0.0000323，分类无差异；这只是小样本检查，不能保证完整设备数值一致。
- 本轮只确认干净 holdout；未重新评估其他候选模型、未执行 holdout 扰动矩阵、未解码官方 test。先前发现的格式偏差和缩放鲁棒性局限仍然存在，同来源 holdout 不能证明跨来源泛化。
- 36 项自测通过，包括 holdout 与训练组重叠拒绝、保存预测被修改时拒绝复用。
