## 环境与数据恢复

使用项目内 `.venv`，Python 3.12、PyTorch 2.5.1+cu118、NumPy 2.4.4、Pillow 12.2.0、Matplotlib 3.11.1。全局 Anaconda Python 是 CPU 版 torch 和旧 NumPy，不能用于正式训练。

通常新机器可执行：

```powershell
py -3.12 -m venv .venv
.\.venv\Scripts\python.exe -m pip install torch==2.5.1 --index-url https://download.pytorch.org/whl/cu118
.\.venv\Scripts\python.exe -m pip install -r requirements.txt
.\.venv\Scripts\python.exe -X utf8 -m tools.fetch_official_data
.\.venv\Scripts\python.exe -X utf8 -m tools.verify_data_handoff --recompute-statistics --output validation/member2_data_pipeline.json
```

本机沙箱中创建 `0o700` 临时目录会出现 WinError 5，沿用 `tools/__init__.py` 的兼容方式；安装时通过仅供本机使用的 `.bootstrap/sitecustomize.py` 导入 `tools`，并将进程的 `PYTHONPATH` 设为项目根目录和 `.bootstrap`。这是安装环境处理，不进入模型、图像增强或实验源码哈希。网络环境存在无效代理以及 `PIP_NO_INDEX=1`；本轮仅在下载/安装进程中清空相应变量，不修改系统设置。下载工具的 `--direct` 可忽略环境代理。

`tools.fetch_official_data` 固定官方 Hugging Face 提交版本并在解压前检查 2,065,749,665 字节及 SHA256；不读取测试像素。原图包缓存在 `downloads/`。训练前核对 8,000 训练图及 1,000 无标签 test 的字节哈希、冻结划分和 train-only 统计，不生成 holdout loader。

## 运行与恢复

包根目录执行：

```powershell
.\.venv\Scripts\python.exe -X utf8 -m unittest discover -s tests -v
.\.venv\Scripts\python.exe -X utf8 -m tools.run_member2 --preflight-only
powershell -ExecutionPolicy Bypass -File .\run_member2.ps1
```

顺序固定 B17→C17→D17→B29→C29→D29→B43→C43→D43。每组 20 epoch，224/width32/batch16/workers0，AdamW，lr 0.001，weight decay 0.0001；不加载 G/A checkpoint。训练器在每个完整 epoch 后保存 last.pt，最佳 dev checkpoint 保存为 best.pt，平分按低 BCE 再按早 epoch 选择，阈值固定 0.5。

再次运行同一入口会审计并跳过完成的 run，对部分 run 从原 last.pt 恢复。不得改源码、配置、数据版本后续写同一 run。`.runner.lock` 防止重复启动；如进程被强制终止并留下锁，先确认对应 PID 及训练子进程均已退出，再手工移除该锁，不能在仍有训练进程时移除。

## 交给成员3

- `runs/member2/<组>_seed<种子>/`：九套 config、metadata、environment、metrics.jsonl、best.pt、last.pt、dev_predictions.csv。
- `validation/member2_execution_freeze.json`：本次执行冻结的源码、配置、adapter、划分和统计哈希。
- `validation/member2_data_pipeline.json`：官方数据完整性、train-only 统计与配对 batch 核验。
- `results/member2/`：仅在九次完整后生成正式汇总、配对差值、训练曲线和逐 run 证据；`progress.json` 是实际进度快照。
- `docs/模型训练_方法章节草稿.md`、`docs/member2_method.tex`：方法与设置稿；`docs/成员2_BCD结果与分析.md` 在九次训练与审计完成后生成。

开发集被用于选择 checkpoint，开发集 Accuracy 不能称为最终独立泛化成绩。B−A、D−C包含增加参数的影响；需成员3 E/F 同容量对照。无 JS 组也保留完全相同的 JPEG 两视图监督。格式偏差（真实全 JPEG、AI 全 PNG）与短边不足224的 813 张图需进入局限分析。
