## 5. 环境与临时目录注意事项（实测）

- Python 3.12.7（Anaconda）、PyTorch 2.5.1 + CUDA 11.8、NumPy 2.4.4、Pillow 12.2.0、Matplotlib 3.11.1、RTX 4060 Laptop 8 GB；本机峰值显存约 1.94–2.03 GB。
- 每 epoch 中位耗时约 121–140 s（六次 run 实测）；G_seed17 日志里约 9.2 小时的 epoch 计时合计是暂停挂起被计入，不是真实速度，原始值保留。
- **临时目录 ACL**：本机沙箱下 `tempfile.mkdtemp` 创建的 0o700 目录会得到当前进程无法访问的 ACL，报 `PermissionError: [WinError 5] 拒绝访问`。`tests/__init__.py` 与 `tools/__init__.py` 已内置兼容层（用默认权限建目录），**不要删除**。若在新机器仍是 WinError 5，把 `TMP`/`TEMP` 指向普通可写目录再跑。
- 详见 `环境与已知问题.md`。
