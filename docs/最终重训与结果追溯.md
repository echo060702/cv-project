# 最终重训与结果追溯

研究run通过dev选择best.pt；内部确认集用于冻结后的评价。最终提交模型在方法已确定后用全部官方有标签数据训练，固定轮数，不再用dev/holdout挑epoch。

## 前置交接

1. 成员3提供模型选择摘要文件（记录dev均值、成本及选定方法）和评估冻结文件（方法/checkpoint/阈值/推理规则已定，后续确认结果不改设计）。
2. 成员2依据开发阶段选出的规则填写最终epoch，不由holdout或排行榜反馈决定。
3. team_data:build_refit_loaders已实现；成员2在评估冻结后执行tools.prepare_data refit生成全量清单和统计。训练loader包含全部官方有标签图，metadata中train为完整清单，dev/holdout ID和group列表为空，split_sha256对应新的全量清单。dev_loader为None。禁止官方test进入。
4. 成员2将选定的七组配置之一复制成根目录 `final_config.json`，保持冻结方法与超参数，设置 `data.manifest` 指向冻结后生成的全量清单（例如data/all_labeled.csv），设置data.statistics为data/all_labeled_statistics.json，核对root与seed；不要覆盖七组研究配置。
5. 研究数据与接口已交付；模型选择摘要、评估冻结、最终配方和全量清单尚待后续正式实验完成。下面命令只用于对应交接到齐后。

## recipe字段

最终recipe JSON含 `epochs`（实际冻结轮数，整数≥2）、`selected_experiment`（例如B）、`selection_summary_sha256` 和 `evaluation_freeze_sha256`（两个真实文件的SHA256）。用 `Get-FileHash -Algorithm SHA256` 或Python hashlib计算，将十六进制转为小写。此处不提供伪造的正式recipe。

```powershell
python -X utf8 -m cvdetect.refit --config final_config.json --adapter team_data:build_refit_loaders --recipe final_recipe.json --selection-summary selection_summary.json --evaluation-freeze evaluation_freeze.json --output runs/final_B_seed17 --device cuda
```

`final_config.json`、`final_recipe.json`、`selection_summary.json`、`evaluation_freeze.json` 是待团队产生的真实文件，不在包中伪造。上例的B只是输出目录示例，实际按所选方法命名。CLI核对两个SHA256并保存recipe。正式config需frozen_budget，数据metadata仍需official。

输出 `final.pt`、config、metadata、recipe、metrics；每epoch覆盖保存当前权重，最后一轮为提交模型。其metrics仅含训练指标，没有dev_accuracy，不得作为独立测试成绩。当前final refit入口没有中断续训CLI；如中断，保留run后在新目录从头重训，不能冒充完成轮数。正式研究训练器支持按epoch恢复。

加载final.pt与best.pt使用同一个 `cvdetect.inference.load_detector`，成员3负责测试预处理与CSV。最终加载接口已用合成全量fit测试，但真实全量数据训练尚未执行。

## 版本与归档

每个结果至少关联源码SHA256、配置、adapter路径、data_revision、split_sha256、seed、epoch和checkpoint SHA256。CLI额外记录adapter工厂所在源文件的SHA256，helper模块与数据版本的完整追溯仍由数据适配器data_revision及交付清单承担。当前非Git仓库，源码SHA256由cvdetect/*.py实际字节计算；团队启用Git后额外记录commit，不编造commit号。

改变增强、划分、版本或预算即产生新实验。恢复仅用于同配置的last.pt，不能用改了epoch的配置续写旧记录。输出目录拒绝覆盖；模型权重、优化器、调度器和AMP状态一起保存。不要仅共享best.pt丢掉其元数据与日志。
