## 实际工程测量

Python3.12.7，PyTorch2.5.1，CUDA11.8，RTX4060 Laptop，8,188MiB总显存。B/C/D均在224×224、width32、每视图batch16（合并32输入）的AMP优化步骤中通过有限梯度与AdamW更新。PyTorch峰值allocated显存分别为2,089,738,752 / 2,000,589,824 / 2,118,554,624字节，约1.95/1.86/1.97GiB；不代表整机显存、完整epoch峰值或正式吞吐。

B/D融合模型2,888,897参数；C单RGB模型2,795,297参数。合成32×32、width4的B/C/D各跑6epoch，日志、best/last及预测位于validation/smoke。亮度可分的合成任务达到可拟合状态，仅证明工程链路可学习，不支持AI识别准确率或残差有效性。

历史工程自动测试共10项；原始输出 `validation/unit_tests_round1.txt`。断点恢复逐位一致只在本机CPU及确定性fixture上验证；GPU正式数据与多worker恢复一致性尚未验证。GPU小样本训练与加载已验证，不能将CPU恢复结论外推为任意设备都逐位一致。
