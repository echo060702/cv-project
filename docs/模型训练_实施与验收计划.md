## 文件与步骤

1. `tests/test_core.py`：先定义随机初始化模型的输出、梯度、残差恒定输入、B/E 与 D/F 参数匹配、JS 对称性及数值稳定性、禁止分组泄漏的行为测试。运行 `python -m unittest tests.test_core -v`，先确认缺少实现而失败，再实现 `cvdetect/model.py`、`losses.py`、`contracts.py`。
2. `cvdetect/engine.py`、`train.py`、`inference.py`：实现两视图训练、干净开发集选择、逐图概率、原始日志、best/last checkpoint、优化器/调度器/AMP/RNG 状态与按 epoch 恢复。`tests/test_training.py` 验证一段训练与中断恢复的一致性，以及只用 train/dev。
3. `configs/G.json` 至 `F.json`：固定七组结构开关与相同训练配方，正式预算冻结前标记 provisional。`tests/fixtures/synthetic_adapter.py` 仅提供工程验证数据，metadata 明确标注 synthetic，不是成员2的正式数据实现。
4. `tools/smoke_check.py`：在可用 CUDA 上验证正式尺寸前向/反向和 B/C/D 小样本拟合，保存工程日志与 checkpoint；不生成竞赛准确率。运行命令和实际输出记录到验证目录。
5. `README.md`、`docs/数据交接接口.md`、`docs/成员2接手指南.md`、`docs/成员3接手指南.md`、`docs/架构与方法.md`、`docs/预期结果与验收.md`、`docs/模型训练_方法章节草稿.md`：给队友提供从解压、安装、验证到各自任务的完整入口。
6. 两轮独立检查：第一轮核对职责覆盖、代码测试、文档/配置/证据齐全；第二轮从 ZIP 解压到新目录，核验 SHA256、相对路径、离线测试和一条真实训练命令可运行。打包不含真实数据、账户凭据、虚拟环境或浏览器会话。

## 验收命令与判据

- `python -m unittest discover -s tests -v`：功能与泄漏边界测试全部通过。
- `python -m cvdetect.train --config configs/B.json --adapter tests.fixtures.synthetic_adapter:build_loaders --output runs/example_B --epochs 2 --batch-size 8 --width 4 --image-size 32 --device cpu`：生成明确标注 synthetic 的 config、metrics、best/last checkpoint、开发预测；正式配置文件保持不变。
- `python tools/smoke_check.py --output validation/smoke`：验证 GPU 与 B/C/D 工程拟合，输出实际结果，不预填成功。
- 解压后同样命令通过，包内文件清单与 SHA256 全部一致；报告列出正式训练未完成的依赖。
