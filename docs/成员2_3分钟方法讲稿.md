# 成员2方法讲稿（约3分钟）

配合团队结构图与消融表使用。展示中的最终数字从 `results/member2/summary.csv` 读取；训练未完成前不填成绩。

## 0:00～0:35：问题与设计

“我们的任务是判断图像是真实拍摄还是AI生成。课程禁止使用预训练，因此所有网络都从随机初始化开始。我们主要检验两个设计：局部残差信息是否有帮助，以及同一张图经过JPEG重编码后，约束预测一致是否有帮助。我们把这两个开关拆开，避免只报告最终模型比基线高多少。”

## 0:35～1:25：模型结构

“RGB主干是一个宽度32的ResNet-18型网络。输入卷积采用步长1，不使用初始最大池化，希望保留局部细节。对224大小的局部裁剪提取256维特征。辅助输入是原图减去3乘3均值平滑结果得到的固定残差，经过三层轻量卷积得到128维特征，再与RGB特征拼接分类。这个固定滤波器没有可训练参数。”

“融合模型比单RGB增加约3.35%的参数。为检验收益是否只是来自新增容量，我们还提供完全相同辅助网络、改输入为RGB的E/F对照。E/F由成员3负责，因此残差效果的解释要结合这些结果。”

## 1:25～2:10：损失与一致性

“每张训练图有原始和JPEG两种视图，两者共享翻转与裁剪位置。我们先在整幅图上重编码，再裁剪同一区域，避免压缩边界和内容位置不一致。所有组都对两视图使用分类损失；一致性开关只控制额外的JS项。这样，C相对A、D相对B的差异才能用于检验一致性项。”

“JS衡量两个Bernoulli预测分布的差异，系数在训练前10%的步数中增加到0.1。两视图拼接在一次前向中，BatchNorm共同观察两种视图。”

## 2:10～3:00：公平对照与边界

“A/B/C/D组成残差与一致性的2乘2消融。所有组共享5600/1200/1200划分，三个种子17、29、43，20轮训练和相同优化器。开发集按准确率选择checkpoint，平分看BCE，再看较早轮次。我们报告三种子的均值、样本标准差和同种子的配对差值。”

“开发集参与了checkpoint选择，不能当作独立测试成绩。另外真实图全部JPEG、AI图全部PNG，存在格式与来源捷径；增强并不保证消除这些偏差。独立评价、退化诊断和冻结后的保留集确认交给成员3。最终全量模型会在方法与评估规则冻结后训练，不用保留集调方法。下面由成员3介绍评价与结果。”
